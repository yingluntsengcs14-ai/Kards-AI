# KARDS AI 復盤介面（期末展示）

```
python tools/demo/server.py --model runs/champion.pt
```
或直接點兩下 repo 根目錄的 `開啟復盤介面.cmd`，瀏覽器會開 http://127.0.0.1:8770 。
（訓練監控用 8765，兩個可以同時開。）

- **雙方控制**：P1／P2 各自選「人工操作」或一種 AI。人工操作時，右側「合法動作」點一下就走那一步，可以用來模擬「對手如果這樣出」。
- **自由出牌（模擬真實對手）**：上方「自由出牌」選 P2（預設），開局會清空 P2 的手牌。輪到 P2 時，在「自由出牌」面板搜尋任何一張卡（這套牌組的卡，或兩個國家的所有卡）加入手牌，需要的話調整指揮點，再到「合法動作」打出它、選目標。手牌上的 ✕ 可移除。這些編輯都會記在時間軸、存進紀錄。之後輪到 P1，AI 就會根據場面判斷下一步。注意：P2 每回合開始仍會照規則從牌庫抽一張，不想要可以再移除。
- **AI 建議**：對目前輪到的一方跑搜尋，列出每個合法動作的搜尋佔比、走這步後的評估、先驗、人工盤面評分。點表格任一列＝走那一步；「照 AI 建議走」＝走最佳那一步。
- **時間軸**：點任一步回到那時的局面。在那裡改走別的動作就是分支；沒改的話可以用「下一步（照紀錄）」繼續看原本的走法。
- **存紀錄／載入紀錄**：對局存成 JSON（牌組、種子、每一步的動作編號），之後載入就能重看。
- 「隱藏對手手牌」只影響畫面。AI 分析用的是完整資訊（看得到雙方手牌與牌庫順序），跟訓練時的 perfect-information 搜尋一致。

卡牌中文名稱與說明來自 kards.com 官方卡牌收藏頁（`data/source/card_names_zh.json`，1,646 張全部有對應）。
